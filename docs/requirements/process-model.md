# Software Process Model

## Selected Model: Incremental Process Model

The Incremental Process Model is selected for the development
of Study Abroad Hub.

In this model, the software is developed and delivered in
small functional increments. Each increment adds new
functionality to the existing system.

## Reason for Selection

1. The project has a limited development timeline.
2. The system can be developed in smaller manageable parts.
3. Each feature can be tested after implementation.
4. Changes can be made without rebuilding the entire system.
5. It is suitable for a beginner-level project with clearly
   identifiable core features.

## Application to Study Abroad Hub

The development will progressively add:

- University and program information.
- Search and filtering.
- Eligibility checking.
- Program shortlisting.
- Optional AI assistant.

Each increment will be integrated with the existing application.
